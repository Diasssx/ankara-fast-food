# ANKARA FAST FOOD — Байконур

Новый React/Vite сайт доставки еды.

## Запуск

```bash
npm install
npm run dev
```

Для production-проверки:

```bash
npm run build
```

## WhatsApp

Открой `src/components/CheckoutModal.jsx` и замени:

```js
const WHATSAPP_NUMBER = "ВСТАВЬ_НОМЕР";
```

на номер в международном формате без `+`, например `77001234567`.

## Что реализовано

- современный тёмный UI ANKARA;
- адаптивный header для desktop/mobile;
- категории со стрелками и горизонтальным scroll;
- поиск по названию, описанию и категории;
- рабочие фильтры и сортировка;
- карточки товаров;
- выбор объёма с отдельной ценой;
- корзина с количеством и удалением;
- сохранение корзины через localStorage;
- checkout;
- доставка / с собой;
- Kaspi / наличные;
- WhatsApp-заказ;
- toast после добавления;
- responsive 1440 / 1280 / 1024 / 768 / 520 / 390 px.

Фотографии блюд можно заменить в `ProductCard.jsx`, когда будут реальные изображения меню.


## Mobile
Версия оптимизирована в первую очередь под телефон: компактная шапка, горизонтальные категории, 2 карточки в ряд и фиксированная кнопка корзины снизу. Скриншоты страниц меню в карточки товаров не вставляются.
